# PF Lab 08 – Post Lab Tasks

Another set of C programming exercises! This repository contains 9 post-lab tasks focused on functions, pointers, arrays, and practical problem-solving.

### What's Included?
- Student attendance management using 3D arrays
- Swapping values using pointers
- Basic calculations using pointers
- Electricity bill calculation
- Salary and bonus calculation
- Loan eligibility checker
- Number analyzer (Even/Odd, Prime, Palindrome)
- Delivery charges calculator
- ATM menu-based banking system

### Concepts Practiced
- Functions and pointers
- 3D arrays
- Conditional statements
- Loops and nested conditions
- Switch statements
- User input and output
- Basic calculations and logical problem-solving

### Tools Used
- C Programming
- Visual Studio Code
- Dev-C++
- GCC Compiler

All tasks are implemented in C with their respective outputs.
